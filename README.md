# Enunciado: Desafio Extra
O projeto tem que:
Colocar mais um led e desenvolver umalógica onde aperta 1 vez o botão ligue o LED1, apertar uma segunda vez ligue o LED 2, apertar uma terceira vez desligue.

Nesse caso, a sequência fica:
- 1º aperto: acende o LED 1.
- 2º aperto: apaga o LED 1 e acende o LED 2.
- 3º aperto: apaga o LED 2 (os dois LEDs ficam desligados).
- 4º aperto: volta a acender o LED 1, repetindo o ciclo.

# Materiais Necessários
- 1 x Placa Arduino UNO;
- 1 x Cabo USB;
- 1 x Protoboard;
- 1 x Botão (push button);
- 2 x LEDs;
- 2 x Resistores de 220 Ω;
- 1 x Resistor de 10 kΩ;
- Fios de jumper macho-macho.
